An immersive, full-stack AI weather application that translates natural language into stunning, real-time weather visualizations. 

Unlike traditional weather apps, **Atmos** utilizes an LLM Agent to extract user intent, retrieve live atmospheric data, and dynamically morph the entire UI—including the color palette and a real-time HTML5 Canvas particle engine—to match the current weather condition.

## ✨ Key Features

- **🧠 AI Agent & Tool Calling:** Utilizes LangChain and Groq (Llama 3) to parse natural language (e.g., *"What is the weather in Chennai, India?"*), extract the city/country code, and autonomously call the weather API.
- **🎨 Liquid Glass UI:** A premium, highly responsive frontend built with custom CSS, featuring smooth `@property` color transitions and glassmorphism elements.
- **🌧️ Dynamic Canvas Environment:** A custom JavaScript canvas engine that renders rain, snow, moving clouds, and lightning flashes based on the live weather data.
- **📊 Custom Data Visualization:** Replaces boring text with a vertical "Day-Range Rail" showing the current temperature relative to the day's high and low, alongside animated wind and humidity instruments.
- **⚡ Lightning Fast:** Powered by Groq's ultra-fast LPU inference for near-instant AI responses.

## 🏗️ Architecture & Workflow

This project uses a decoupled architecture. The frontend is entirely driven by a strict JSON response generated by the backend AI.

1. **User Input:** The user types a natural language query into the UI.
2. **Flask Route:** The frontend sends the query to the `/ask` endpoint.
3. **LangChain Agent:** The backend passes the query to the LLM with a strict system prompt.
4. **Tool Execution:** The LLM decides to call the `get_weather` tool, passing the extracted city and country code.
5. **OpenWeather API:** The Python tool fetches the raw data, formats it into a clean JSON object, and returns it to the LLM.
6. **UI Render:** The frontend parses the JSON, updates the numbers, shifts the CSS color variables (`data-sky`), and triggers the Canvas particle animations.

## 🛠️ Tech Stack

**Backend & AI:**
- **Python (Flask):** Web server and API routing.
- **LangChain:** Agent orchestration and tool-binding.
- **Groq API:** High-speed LLM inference (using `openai/gpt-oss-20b` or Llama 3).
- **OpenWeatherMap API:** Real-time global weather data.

**Frontend:**
- **Vanilla JavaScript:** DOM manipulation and fetch API.
- **HTML5 Canvas API:** Procedural particle generation for rain, snow, and clouds.
- **Advanced CSS:** Houdini properties (`@property`), CSS Grid, Flexbox, and Glassmorphism.

## 🚀 Getting Started

Follow these steps to run the application locally.

### 1. Prerequisites
You will need free API keys from two services:
- **OpenWeatherMap:** [Sign up here](https://openweathermap.org/api) to get your `OPENWEATHER_API_KEY`.
- **Groq:** [Sign up here](https://console.groq.com/) to get your `GROQ_API_KEY`.

### 2. Clone the Repository
```bash
git clone https://github.com/yourusername/ai-weather-agent.git
cd ai-weather-agent


### 3. Set Up Virtual Environment
```bash
# Windows
python -m venv .venv
.\.venv\Scripts\Activate

# macOS/Linux
python3 -m venv .venv
source .venv/bin/activate
```

### 4. Install Dependencies
```bash
pip install -r requirements.txt
```

### 5. Environment Variables
Create a `.env` file in the root directory and add your API keys:
```env
GROQ_API_KEY=your_groq_api_key_here
OPENWEATHER_API_KEY=your_openweathermap_api_key_here
```

### 6. Run the Application
```bash
python app.py
```
Open your browser and navigate to `http://127.0.0.1:5000`.
